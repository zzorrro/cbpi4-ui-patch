# cbpi4-ui-patch

Патч интерфейса CraftBeerPi4 (пакет `cbpi4gui` 0.5.0, файл `main.65b608fc.js`): стабильная ширина кнопок Actor, кнопки +/-, крупное окно мощности и уведомления, настраиваемые размеры.

## Установка (любой пользователь Pi)

    curl -fsSL https://raw.githubusercontent.com/zzorrro/cbpi4-ui-patch/main/install.sh | sudo bash

Скрипт ставит файлы в `/opt/cbpi4-ui-patch`, создаёт команду `cbpi4-ui-patch`, сам находит файл интерфейса и применяет патч. После этого в браузере Ctrl+F5.

## Команды

    sudo cbpi4-ui-patch apply      # применить (или применить заново после правки настроек)
    sudo cbpi4-ui-patch restore    # вернуть оригинальный файл
    sudo cbpi4-ui-patch status     # состояние
    sudo cbpi4-ui-patch uninstall  # вернуть оригинал и удалить патч с системы

## Настройки

    sudo nano /opt/cbpi4-ui-patch/settings.py
    sudo cbpi4-ui-patch apply

При первой установке `settings.py` создаётся полной копией `settings_default.py`: все параметры (размеры и время показа) с описаниями, их можно править прямо в нём. Файл не перезаписывается при обновлении. Параметры, которых в нём нет (новые в будущих версиях), берутся из `settings_default.py` автоматически. Чтобы получить свежую полную копию, переименуйте или удалите `settings.py` и снова запустите установку, либо выполните `sudo cp /opt/cbpi4-ui-patch/settings_default.py /opt/cbpi4-ui-patch/settings.py`.

## Обновление

Повторно выполните команду установки. После обновления пакета cbpi4gui через pip выполните `sudo cbpi4-ui-patch apply`.

## Окно этапа

Окно, которое открывается нажатием на этап в списке Steps (и этапы ферментера), настраивается параметрами `step_dlg_*` в `settings.py` (описание в `settings_default.py`). То же касается окна параметров действия этапа (ширина, заголовок, кнопки Close/Submit).

## Фон кнопки Actor

У элемента Actor появилось свойство `bgcolor` (текст). Пусто (по умолчанию) или `transparent` / `no` - кнопка прозрачная, как раньше. Любой CSS-цвет (`#1e1e1e`, `rgb(30,30,30)`, `black`) - заливка кнопок элемента в выключенном состоянии. Включённая кнопка красится как раньше.

## Окно ручной уставки температуры

Окно «Set Target Temp», которое открывается с панели KettleControl (и FermenterControl), по умолчанию такое же по размерам, как окно мощности. Настраивается параметрами `temp_dlg_*` в `settings.py` (описание в `settings_default.py`).

## Окно очистки уведомлений

Окно «Delete Old Notifications ?» (колокольчик в верхней панели) настраивается параметрами `notif_dlg_*` в `settings.py`.

## Рабочая зона дашборда

`dash_width_px` (0 = на всю ширину окна, как в оригинале; на телефоне при включённой доводке зона уже окна на поля страницы) и `dash_height_px` (1000 = как в оригинале, 0 = на всю высоту окна за вычетом шапки `dash_header_px`). Ширина не превышает ширину окна минус `dash_side_margin_px`. Если зона больше окна, появляется прокрутка. Прокрутка вбок доводится до края колонки: `dash_snap_col_px` (ширина колонки, 0 = выключено) `dash_snap_delay_ms` (пауза после остановки) и `dash_snap_max_window_px` (доводка работает только при ширине окна не больше этого значения, по умолчанию 700 = телефоны). Масштаб страницы на телефоне: `mobile_viewport_px` (ширина страницы в CSS-пикселях, 358 = колонка 295 + поля 63, 0 = выключено) и `mobile_viewport_max_px` (только для экранов, у которых меньшая сторона не больше этого значения).

## Масштабирование готового дашборда

`scale_dashboard.py` пропорционально уменьшает или увеличивает файл дашборда (координаты, ширины, размеры текста, линии):

```
python3 scale_dashboard.py cbpi_dashboard_1.json cbpi_dashboard_1_new.json 0.55
```

Кнопки котла (KettleControl) имеют фиксированный размер и не масштабируются.
